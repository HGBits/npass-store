# AGENTS.md - man

## Escopo

Manual de uso do `npass`.

## Arquivo

- `npass.1`

## Quando alterar

Atualize este arquivo quando houver mudança de interface pública:

- comando;
- argumento;
- opção;
- variável de ambiente;
- comportamento observável do usuário.

Não use o manual para documentar detalhes internos que não fazem parte da interface.

## Fonte de verdade

A implementação em `lib/` e os testes são a fonte primária do comportamento. O manual deve acompanhá-los, não inventar comportamento.
